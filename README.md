# Maintainable Web App Architecture Workshop

This repo has separate workshop branches. Switch to the branch you want:

```bash
git switch wrapper-pattern
```

```bash
git switch sentry-toturial
```

```bash
git switch refactor-react-component
```

Branches:

- `wrapper-pattern`: wrapper pattern for third-party email providers
- `sentry-toturial`: Sentry React demo
- `refactor-react-component`: messy React component refactoring exercise
- `main`: starting branch
